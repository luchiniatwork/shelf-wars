# Naming & IP — Deep Reference

Load when naming a game, checking trademark/searchability, or evaluating a licensed-IP deal vs. original IP.

## 1. Naming — the League of Gamemakers consensus (verified from "Ask the League: Naming a Game")

Designers quoted: Seth Jaffee, Peter Vaughan, Mike Domeny, Jasmine, Luke Laurie, Teale Fristoe, and
Brad Brooks (first names as bylined in the article). Distilled rules:

1. **Convey feel, spirit, setting** (Seth); an excellent title also **telegraphs weight and style**.
2. **1–2 words ideal.** "If you want to gamify it, every word you use above a single word is minus points"
   (Peter). The name is "the ultimate expression of the game's essence... your hook."
3. **Match tone to weight** (Mike): the more syllabic/complicated/uncommon the words, the heavier the game
   players expect (*Tzolk'in: The Mayan Calendar*, *Twilight Imperium*). **Pun titles ⇒ light game, under
   30 minutes.**
4. **Be original** (Teale): not used by another game; communicate theme, mechanics, weight, mood; preferably
   clever. Brainstorm many candidates before choosing.
5. **Be unambiguous** (Brad): counterexample "Summoner Wars" vs. "Summoners War" (different products, one
   near-identical name). Also: not unwieldy — easy to say, remember, spell.
6. **Provisionally title early** (Jasmine) so playtesters can reference the game; expect retitling.
7. **Crowdsource candidates** (Teale): ask playtesters and social networks; an outside suggestion often wins.
8. **Get objective feedback** (Brad): "what resonates with you might not with others."

**Game Name Gauntlet** (Mike Domeny, League): run finalist names through practical real-world situations —
said aloud across a noisy table, typed into a search box, heard once and recalled a week later, said to a
retailer on the phone, printed on a shelf spine. A name that fails any gauntlet test loses.

## 2. Searchability & collision check (run before falling in love)

| Check | Where | Pass criterion |
|-------|-------|----------------|
| Existing games | BoardGameGeek database | No identical or confusingly near title |
| Digital/app collisions | App Store / Google Play / Steam | No near-name in games (the "Summoners War" trap) |
| Web search | Google the exact phrase | First page isn't owned by something else |
| Domain | Registrar search | .com (or acceptable TLD) available or acquirable |
| Social handles | Major platforms | Consistent handle available |
| Trademark registers | USPTO (uspto.gov), EUIPO | No live conflicting mark in Class 28 |

## 3. Trademark basics for game titles

- **Games register in Nice Class 28** (games, toys, playthings). File word marks (title text) first; logos
  are separate filings.
- **Fees:** USPTO electronic filing has historically run ~$250–$350 per class [contested — fee schedules
  change; check the current USPTO schedule before quoting]. Budget per-class, per-jurisdiction.
- **TM vs. ®:** you may use ™ on an unregistered mark (common-law rights arise from use in commerce); ® is
  lawful only after registration grants.
- **What trademarks protect:** the *title/brand*, not the game. Mechanics are largely uncopyrightable
  (protectable only via patents, rare and slow in tabletop); art and text are copyrightable; the brand is
  trademarkable. Plan protection accordingly: trademark the name, copyright covers art/rulebook text
  automatically on creation, mechanisms rely on speed and brand.
- **Screen early:** a title you must abandon after a Kickstarter launch burns the brand equity you just
  built. Do §2's table before public announcement.
- **Publisher handoff:** publishers often re-title licensed designs; trademark is usually filed by whoever
  publishes. If self-publishing, the filing is on you (see `board-game-publishing` for deal structures).

## 4. IP licensing — what a deal contains and who it's for

**Licensed IP = designing inside someone else's brand** (film, TV, video game, comic). Typical deal anatomy:
- **Advance / minimum guarantee (MG)** against royalties, paid on signing or milestones.
- **Royalty to the licensor:** community-quoted ~8–14% of net sales [contested — highly deal-specific].
- **Approval rights:** licensor approves theme use, art, components, marketing — often through a mandated
  **style guide**; approval cycles add months and can force redesigns.
- **Term, territory, category** limits; renewal and sell-off clauses.
- **No equity:** when the term ends, the brand and its audience stay with the licensor.

**Practitioner consensus (BGDL episodes: "Designing Games Based on a Licensed IP with Daryl Andrews",
"Nolan Nasser on Developing Games for a Licensed IP", "Bringing a Licensed IP to Life"):** licensed work is
viable for experienced designers/developers who can absorb approvals and constraints; it is a **trap for
first-time designers** — you carry the bureaucracy and royalty burden while building someone else's brand.
[Practitioner consensus, not law.]

**Original IP compounds:** every released game grows an asset you own — the name, the world, the art
(per work-for-hire contract terms, see `references/art-direction.md`), the audience. Stonemaier's economics
illustrate the long game: $150,000 invested in Wingspan pre-revenue, building an evergreen owned brand.

## 5. Theme redundancy & the publisher gate

Stonemaier's submission screen (~3,000 submissions over 9 years [contested — figure not found on the cited
submission-guidelines page]) asks, per game: does it bring joy
worldwide; do we love it; does it fit our tenets/vibe; **do we already publish a similar game — mechanically
OR thematically**; evergreen potential; are we excited to teach it repeatedly. Practical implications:
- A winemaking game pitched to the publisher of Viticulture is rejected on theme alone — research the
  target publisher's catalog for thematic adjacency before pitching.
- Differentiate on theme OR mechanisms, explicitly, in the pitch's first line (pitch mechanics themselves:
  `board-game-publishing`).
- Evergreen potential favors themes with broad, durable appeal over trend-chasing; marketing depends on the
  game itself — theme + mechanisms — not structural gimmicks like "it's a campaign."

## 6. Naming-and-IP checklist (copy-paste)

- [ ] 10+ candidates generated; some crowdsourced
- [ ] 1–2 words; easy to say, spell, remember
- [ ] Tone matches weight; pun only if light & <30 min
- [ ] Passes the Game Name Gauntlet (noisy table / search box / one-week recall / phone test / spine test)
- [ ] BGG, app stores, web, domain, handles checked
- [ ] USPTO/EUIPO Class 28 screened; no live conflicts
- [ ] Provisional title assigned for playtests; final title locked before public announcement
- [ ] Decision recorded: original IP (default for first-timers) vs. licensed IP (only with deal terms in
      writing: advance/MG, royalty %, approval scope, style guide, term/territory)
